# Security Policy

## Supported Versions

The latest version on the default branch is supported.

## Reporting a Vulnerability

Do not publish security-sensitive findings as public issues before a fix is available. Contact the repository maintainer privately through the hosting platform's security advisory feature or profile contact method.

MftFileSearch opens local NTFS volume handles and reads MFT/USN metadata. Reports involving privilege boundaries, malformed index files, unsafe path handling, native interop, or denial of service are especially useful.
